An entry for the make.fun bounty
[One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36):
send exactly one letter, A to Z, standing for the word that describes your
day, and let the judge pick the letter whose hidden word feels most vivid,
funny, or true.

## What it does

`main.py` (Python 3, standard library only) writes a single character to
`/output/entry.txt` — one uppercase letter, no newline, no punctuation,
nothing else. The competition gate accepts UTF-8 text of 1 to 1 characters,
so the program guards that contract with an assertion before writing.

## Run it

```bash
python3 main.py
cat /output/entry.txt
```
